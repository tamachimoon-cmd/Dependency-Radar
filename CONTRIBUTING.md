# Contribuindo

1. Abra uma issue descrevendo o problema ou melhoria.
2. Crie uma branch a partir de `main`.
3. Faça alterações pequenas, com testes em `node --test` e verificação em `npm run check`.
4. Abra um Pull Request com descrição e passos de validação.

Não inclua dados corporativos, segredos, credenciais ou manifestos privados.
