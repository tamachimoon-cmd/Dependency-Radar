# Segurança

Para relatar vulnerabilidades, utilize o recurso **Report a vulnerability** na aba Security do GitHub, se disponível. Evite divulgar detalhes exploráveis em issues públicas.

O projeto realiza análise estática e não executa dependências. Não é um scanner de CVEs ou auditoria de licenças. Use somente manifestos que você tem autorização para analisar. Não exponha a aplicação publicamente sem autenticação e controles adicionais.
